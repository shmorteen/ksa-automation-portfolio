DEMO SOURCE / HOW IT WORKS

Four workflows.
Real logic, sample data.

These small Python references correspond to the interactive demos on the portfolio homepage. They show business rules, validation and JSON outputs without touching any live system.

Transparent scope: These are self-initiated concept demos, not client implementations. They do not connect to a CRM, payments, messaging system or external service. No production benefits or customer results are implied.
01 / SALES

Lead intake and routing

Receives lead details, computes a rule-based priority score and prepares an unsent CRM payload.

Run them locally

Clone or download the GitHub repository, open a terminal inside demo-workflows and run:

python workflow_demos.py lead
python workflow_demos.py clean
python workflow_demos.py orders
python workflow_demos.py reports
python -m unittest discover -s tests -v
